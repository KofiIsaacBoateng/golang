### GOROUTINES

```go
// This is a tutorial project using [goroutines] to master go concurrency!
// Two main files. One that focuses mainly on goroutines and another that adds
// a layer of complexity introducing me to new concepts before I master them.
```

1. File Searcher -> goes through a list of files and concurrently print whether it found matches to a search term.
2. File Searcher 2.0 -> takes a directory and prints all matches of the seach term in the directory tree.
3. Also 2.0 -> prints out the matched file tree, the match and their line numbers.
